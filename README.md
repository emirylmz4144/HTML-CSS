# HTML ve CSS

Bu depo, HTML ve CSS öğrenme sürecindeki konu örneklerini ve arayüz çalışmalarını içerir. ve düzen aşağıdaki gibidir.

## Kategoriler

- **HTML/**: HTML belge yapısı ve semantic HTML örnekleri.
- **CSS/**: CSS animasyonları, hover efektleri ve Grid yerleşimleri.
- **Bootstrap/**: Bootstrap kullanılarak hazırlanmış arayüz çalışmaları.
- **Web Sitesi Projeleri/**: Belirli web sitelerini örnek alan veya yeniden oluşturan çalışmalar.
